# Исходный код (Этапы разработки)

В этой папке находятся Python-скрипты, демонстрирующие пошаговое создание трассировщика лучей. Каждый файл — это отдельный этап, который можно запустить независимо.

## Список файлов и этапов

1. **`step_01_gradient.py`** — Отрисовка простого градиента с помощью буфера кадра.
2. **`step_02_sphere.py`** — Реализация математики векторов и пересечения луча со сферой.
3. **`step_03_multiple_spheres.py`** — Отрисовка сцены из нескольких сфер.
4. **`step_04_diffuse_lighting.py`** — Добавление точечных источников света (модель Ламберта).
5. **`step_05_specular_lighting.py`** — Добавление зеркальных бликов (модель Фонга).
6. **`step_06_shadows.py`** — Реализация теней (проверка перекрытия лучей к источникам света).
7. **`step_07_reflections.py`** — Рекурсивная трассировка отраженных лучей.
8. **`step_08_refractions.py`** — Реализация закона Снеллиуса для прозрачных материалов (стекло).
9. **`step_09_floor_chessboard.py`** — Добавление плоскости пола с шахматной текстурой.
10. **`step_10_envmap.py`** — Наложение сферической карты окружения (EnvMap) на фон.
11. **`step_11_final.py`** — Пересечение луча с треугольниками (алгоритм Моллера-Трумбора) и отрисовка полигональной модели (пирамиды).

Скрипты используют библиотеку Pillow (для шагов 10 и 11), поэтому перед запуском убедитесь, что она установлена:
